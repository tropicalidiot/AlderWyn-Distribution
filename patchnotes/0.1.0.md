# AlderWyn 0.1.0 — Outdoor crafting preview

The first packaged development preview of the outdoor crafting area.

- Explore the crafting clearing with the textured farmer character and idle, walk and run animations.
- Third-person movement: WASD to move, mouse to turn the camera, and Shift to run.
- Approach a workbench, sawmill or smelter and press E to open its crafting menu.
- Choose a recipe and quantity, then start crafting. Station activity loops for the crafting duration; return to collect completed items.
- Outdoor foliage includes refined trees, subtle leaf/grass/flower wind, and a smelter with glowing coals and smoke while active.

This is a single-player development preview. Multiplayer and hosted servers are not included.

The macOS game targets both Apple silicon and Intel. This package was built on Windows using Unity's macOS support. Native Mac gameplay and launch behavior still need verification. Game and launcher are unsigned development packages, not Apple-notarized releases.
